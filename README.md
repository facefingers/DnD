# 🎲 Интерактивный лист персонажа D&D

Удобный веб-интерфейс для просмотра информации о персонаже D&D с возможностью бросков костей.

![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/javascript-%23323330.svg?style=flat&logo=javascript&logoColor=%23F7DF1E)

## ✨ Особенности

- 📱 **Адаптивный дизайн** - отлично выглядит на мобильных устройствах
- 🎯 **Интерактивные броски** - нажимай на кнопки для бросков костей
- 🎨 **Красивый интерфейс** - современный дизайн с градиентами и анимациями
- 📊 **Организованная структура** - все данные разделены по вкладкам
- 💾 **Сохранение вкладок** - запоминает последнюю открытую вкладку
- 🔊 **Звуковые эффекты** - звук при броске костей

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/dnd-character-sheet.git
cd dnd-character-sheet
```

2. Откройте `index.html` в браузере:
```bash
# На Windows
start index.html

# На Mac
open index.html

# На Linux
xdg-open index.html
```

Или просто дважды кликните на файл `index.html`.

## 🎮 Использование

### Броски костей
Просто нажмите на любую кнопку с формулой броска:
- Система автоматически бросит кости
- Результат появится в правом нижнем углу
- Результаты исчезают через 5 секунд

### Кастомные броски
Откройте консоль браузера (F12) и используйте:
```javascript
customRoll(2, 6, 3, "Моя атака")
// 2к6 + 3 с названием "Моя атака"
```

### Переключение вкладок
- Нажмите на вкладку вверху страницы
- Последняя открытая вкладка сохраняется автоматически

## 🎨 Кастомизация

### Изменение цветов
Отредактируйте CSS переменные в начале `style.css`:
```css
:root {
    --color-blue: #3b82f6;
    --color-purple: #8b5cf6;
    /* ... */
}
```

### Добавление нового заклинания
Добавьте карточку в раздел заклинаний в `index.html`:
```html
<div class="card card-blue">
    <h3>🔥 Огненный шар</h3>
    <div class="spell-meta">
        <span class="badge level-1">3-й уровень</span>
        <span class="badge">Действие</span>
    </div>
    <p>Описание заклинания...</p>
</div>
```

### Добавление нового броска
Добавьте обработчик в `script.js`:
```javascript
'fireball': () => {
    const rolls = rollMultipleDice(8, 6);
    const total = rolls.reduce((a, b) => a + b, 0);
    showRollResult('Огненный шар', total, `8к6(${rolls.join(', ')})`);
}
```
